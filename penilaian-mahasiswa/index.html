Backend Google Apps Script Terhubung Baku / Hardcoded

URL Web App Apps Script telah tertanam permanen di sistem, sehingga seluruh perangkat otomatis tersinkronisasi tanpa perlu input URL manual.

Panduan 3 Langkah Memasang Apps Script:
  1. Buka Google Spreadsheet > Menu Ekstensi > Apps Script.
  2. Hapus seluruh isi Code.gs, tempelkan kode Apps Script terbaru via tombol Salin Kode Backend di atas, lalu tekan Simpan (Ctrl+S).
  3. Deploy Versi Baru (Wajib agar Perubahan Aktif di Cloud):
    1. Klik Terapkan (Deploy) > pilih Kelola penerapan (Manage deployments).
    2. Klik ikon Pensil (Edit) pada penerapan aktif.
    3. Pada dropdown Versi (Version), pilih Versi baru (New version).
    4. Pastikan akses: Siapa saja (Anyone).
    5. Klik Terapkan (Deploy). Selesai!
